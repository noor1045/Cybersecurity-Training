# WPScan

WPScan is a WordPress security scanner preinstalled in Kali Linux. It is used to identify security vulnerabilities in WordPress websites, including outdated plugins, weak themes, misconfigurations, and login security weaknesses.

It helps penetration testers and security researchers assess WordPress site security.

> **Disclaimer:** WPScan should only be used against websites that you own or have explicit authorization to test.

## Key Features

1. Detects WordPress version and checks for vulnerabilities.
2. Enumerates themes, plugins, and users.
3. Supports testing of WordPress login security.
4. Uses an updated vulnerability database.
5. Can work with API tokens for detailed vulnerability results.

## Install WPScan

Update the package list and install WPScan:

```bash
sudo apt update && sudo apt install wpscan -y
```

This installs WPScan and its required dependencies.

##  Verify Installation

Check the installed version:

```bash
wpscan --version
```

If the version information is displayed, WPScan has been installed successfully.

## Run WPScan Against Target URL

Run WPScan using the target URL:

```bash

```

The target URL should only be a WordPress website that you own or are authorized to test.

### Random User Agent

If an error occurs while scanning, the notes instruct adding:

```text
--random-user-agent
```

This makes WPScan use a random browser-style User-Agent during the request.
