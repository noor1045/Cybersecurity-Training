
# MASSCAN

MASSCAN is a high-speed port scanner designed for fast and large-scale network port discovery. It is commonly used for network reconnaissance, security research, and authorized vulnerability assessment.

## Installation

First, update the package list:

```bash
sudo apt update
```

Install MASSCAN:

```bash
sudo apt install masscan -y
```

## Verify Installation

After installation, verify that MASSCAN is installed correctly:

```bash
masscan --version
```
