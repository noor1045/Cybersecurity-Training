## Task Overview

In this task, I installed and used Dradis Community Edition in Kali Linux.

Dradis is a collaboration and reporting platform used during penetration testing and security assessments. It helps organize and manage results generated by tools such as Nmap, Burp Suite, Nessus, OpenVAS and Metasploit.

## Dradis Installation

I installed Dradis using:

`sudo apt install dradis -y`

After installation, I tried to start the tool using the command shown in the manual:

`sudo dradis`

The terminal showed that this command was deprecated and suggested using:

`sudo dradis-start`

I used the updated command and the Dradis service started successfully.

## Opening Dradis

Dradis was opened in Firefox using:

`http://127.0.0.1:3000`

During the initial setup, I created a shared password and completed the setup process.

After setup, the Dradis project dashboard opened successfully.

## Dashboard

The dashboard included sections for:

- Nodes
- Issues
- Evidence
- Notes
- Methodologies
- Attachments

These sections can be used to organize hosts, services, vulnerabilities and assessment evidence.

## Importing the Nmap Report

I opened the upload section and selected the following Nmap XML report:

`nmap_scan.xml`

At first, the wrong plugin was selected automatically. I changed the plugin to:

`Dradis::Plugins::Nmap`

The uploaded record state was kept as:

`Draft`

I then selected the Nmap XML file again and started the upload.

## Import Result

Dradis successfully processed and validated the Nmap report.

The output console showed:

- New host: `127.0.0.1`
- New port: `80/tcp`
- Worker process completed

This confirmed that the Nmap report was imported successfully.

## Imported Host Details

The imported host appeared under the Scanner output section.

The following information was shown:

- Hostname: `localhost`
- IP address: `127.0.0.1`
- Protocol: `TCP`
- Port: `80`
- State: `Open`
- Product: `SimpleHTTPServer`
- Service: `HTTP`
- Version: `0.6`

## Result

The Dradis installation, setup and Nmap report import were completed successfully.

The imported host and service information was organized inside the Dradis project dashboard.
