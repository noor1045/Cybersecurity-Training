# Day 22 - theHarvester

## Overview

theHarvester is an open-source OSINT (Open Source Intelligence) tool used to gather information such as:

* Email addresses
* Subdomains
* IP addresses
* Hostnames

It collects information from public sources including search engines, DNS records, and data breach databases.

theHarvester is commonly used during the reconnaissance phase of ethical hacking and penetration testing. It helps security professionals map a target's external information without direct interaction with the target system.

---

## Installation / Availability

theHarvester is a pre-installed tool in Kali Linux.

No additional installation was required.

The tool can be accessed directly from the Kali environment.

---

## Information Gathering

theHarvester was used to collect publicly available information about the target.

The tool can gather:

* Domain information
* Email addresses
* Hostnames
* Subdomains
* IP addresses

This information helps during the reconnaissance phase of a security assessment.

---

## Target Analysis

During the assessment, the target website was analyzed using theHarvester.

The collected information included publicly available email addresses associated with the target domain.

The CUST website was also checked, where an email address was identified during the information gathering process.

---

## OSINT Reconnaissance

theHarvester helps security professionals perform passive reconnaissance by collecting publicly available information before conducting further security testing.

The gathered information can help identify:

* Possible attack surfaces
* Associated domains
* Public contact information
* External infrastructure details

---

## Conclusion

theHarvester is a useful OSINT reconnaissance tool included in Kali Linux.

This practical demonstrated how theHarvester can be used to collect publicly available information such as emails, domains, subdomains, and host details during the initial phase of ethical hacking and penetration testing.
