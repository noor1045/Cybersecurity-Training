# Cybersecurity_Training

## Overview

This repository documents my hands-on cybersecurity learning and practical work. It includes the tools, commands, configurations, results, and screenshots collected while working in a controlled lab environment.

The purpose of this repository is to build practical experience, understand how different cybersecurity tools work, and maintain clear documentation of the learning process.

## What This Repository Contains

- Cybersecurity tool installation and configuration
- Linux terminal commands
- Web reconnaissance and content discovery
- Reverse engineering and software analysis
- URL, endpoint, and resource discovery
- Binary and memory analysis
- Tool outputs and practical results
- Screenshots as evidence of completed work
- README documentation explaining the process

## Tools and Technologies

The practical work in this repository may include:

- Kali Linux
- Git and GitHub
- Linux command line
- Reconnaissance tools
- Web crawling tools
- Reverse-engineering tools
- Golang-based utilities
- Security analysis software

## Skills Developed

Through this practical work, I am developing experience in:

- Working with the Linux terminal
- Installing and configuring security tools
- Troubleshooting installation and dependency issues
- Performing authorized web reconnaissance
- Discovering URLs, endpoints, scripts, and resources
- Understanding basic reverse-engineering concepts

- Organizing technical work on GitHub

## Documentation

The repository is organized into separate folders for practical activities. Each folder may contain:

- A README file
- Commands used during the practical
- Screenshots of important steps

This structure makes the work easy to review and helps track practical progress over time.

## Purpose

This repository is maintained as part of my cybersecurity learning journey. It serves as a record of practical experience and will continue to be updated as I work with more security tools and techniques.
