# Week 6 - Final Project: SentinelDesk

## Project Overview

This week marks the beginning of the final internship project, **SentinelDesk**.

SentinelDesk is a web-based cybersecurity operations dashboard that will combine multiple security-related utilities into a single application. The project is being developed using **Python and FastAPI** in a **Kali Linux** environment.

The planned modules for the project include:

* Password Audit
* Port Scanner
* File Integrity Monitor
* Log Analyzer

## Project Initiation

The development of SentinelDesk was started by preparing the required environment and setting up the initial project foundation.

The main objective of this stage was to ensure that the development environment was properly configured before moving toward the implementation of individual cybersecurity modules.

## Work Completed

During the initial development session, the following tasks were completed:

* Created the local SentinelDesk project directory.
* Verified the Python installation in Kali Linux.
* Created and activated a Python virtual environment.
* Installed the required Python dependencies.
* Installed and configured FastAPI and Uvicorn.
* Installed Jinja2 and python-multipart for future web interface development.
* Created the initial application directory structure.
* Created a basic FastAPI application.
* Configured the initial home route.
* Successfully launched the application using the Uvicorn development server.
* Verified that the application was accessible through localhost.
* Verified the automatically generated FastAPI API documentation.
